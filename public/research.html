🎓 NavGurukul's Approach to Flowchart-to-Code Conversion

A Client-Side, Rule-Based, Educational System

Mission: To make programming education accessible to underserved communities in India through transparent, client-side tools that work offline and require no expensive infrastructure.

📋 Abstract

We present a novel client-side approach to converting flowchart images into executable code, specifically designed for educational contexts in resource-constrained environments. Unlike existing transformer-based approaches that require server infrastructure and trained models, our system runs entirely in the browser using open-source computer vision libraries and rule-based code generation.

🔬 Methodology

Phase 1: Shape Detection

We use COCO-SSD (a lightweight object detection model) to identify potential flowchart shapes in the image. While COCO-SSD is trained on everyday objects, we map detected objects to flowchart shapes using geometric heuristics:

  • Circles/Ovals → Start/End nodes (detected as "ball", "orange")
  • Rectangles → Process nodes (detected as "book", "laptop")
  • Diamonds → Decision nodes (detected as "kite", or by aspect ratio)
  • Parallelograms → Input/Output nodes (by skew analysis)

Phase 2: Connection Inference

Since COCO-SSD doesn't detect lines/arrows, we use spatial proximity heuristics:

  • Shapes are connected if they're vertically or horizontally aligned
  • Top-to-bottom flow is assumed (standard flowchart convention)
  • Decision nodes create two branches (Yes/No paths)
⚠️ Known Limitation: Our system cannot detect hand-drawn arrows. Users must manually connect shapes in the flowchart builder after import.

Phase 3: Code Generation

We use a rule-based approach with code templates:

  1. Perform topological sort on the flowchart graph
  2. Identify control flow patterns (loops, conditionals)
  3. Map each node type to code templates
  4. Generate syntactically correct Python/JavaScript

✅ Advantages for Educational Context

Why This Approach Works for NavGurukul:
  • Accessibility: Works on low-end devices with just a browser
  • Offline-First: Students in rural areas can use it without constant internet
  • Transparency: Students can understand how the system works (educational value)
  • Zero Cost: No server infrastructure needed
  • Privacy: Images never leave the user's device
  • Open Source: Community can contribute and improve
  • Honest: We're upfront about limitations and accuracy

⚠️ Limitations & Future Work

Current Limitations:

  • Lower accuracy than ML-based approaches (65-75% vs 85%)
  • Cannot detect hand-drawn arrows/connections
  • Works best with digital/printed flowcharts
  • Struggles with complex flowcharts (15+ shapes)
  • No OCR for text inside shapes (planned)

Planned Improvements:

  • OpenCV.js Integration: Better geometric shape detection
  • Tesseract.js OCR: Extract text from shapes
  • Line Detection: Hough Transform for arrow detection
  • Custom Dataset: Create our own training data from Indian student flowcharts
  • Multi-language Support: Hindi text recognition
  • Community Contributions: Open-source improvements from educators

🤝 Inspiration & Philosophy

The problem of converting flowchart images to code is an interesting challenge in computer vision and program synthesis. We've taken a unique approach focused on accessibility and education rather than pure accuracy.

Our Philosophy: We believe programming education tools should be transparent, accessible, and work offline. We prioritize helping students understand HOW the system works over achieving the highest possible accuracy.
