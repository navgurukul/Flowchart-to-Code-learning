📄 LaTeX Paper Compilation Guide

How to compile and submit the research paper

📍 Paper Location: The LaTeX source file is available at docs/paper/paper.tex in the GitHub repository.

🎯 Quick Start

1 Download the LaTeX file
git clone https://github.com/navgurukul/Flowchart-to-Code-learning.git cd Flowchart-to-Code-learning/docs/paper
2 Compile the paper
# Compile once pdflatex paper.tex # Compile twice for references pdflatex paper.tex pdflatex paper.tex
3 View the PDF

Open paper.pdf in your PDF viewer

💻 Prerequisites

Install LaTeX Distribution

Ubuntu/Debian:

sudo apt-get update sudo apt-get install texlive-full

macOS:

brew install --cask mactex

Windows:

Download and install MiKTeX from https://miktex.org/

🌐 Online Compilation (No Installation)

Using Overleaf

  1. Go to https://www.overleaf.com/
  2. Create a free account
  3. Click "New Project" → "Upload Project"
  4. Upload paper.tex
  5. Click "Recompile" to generate PDF
✅ Recommended: Overleaf is the easiest way to compile LaTeX without installing anything!

📤 Submitting to arXiv

Method 1: Direct Upload

  1. Go to https://arxiv.org/submit
  2. Create an arXiv account if you don't have one
  3. Click "Start New Submission"
  4. Upload paper.tex
  5. Select category: cs.CV (Computer Vision) or cs.CY (Computers and Society)
  6. Follow the submission wizard

Method 2: From Overleaf

  1. Open your project in Overleaf
  2. Click "Submit" → "arXiv"
  3. Follow the integration steps
  4. Overleaf will handle the submission automatically
📚 Suggested arXiv Categories:
  • Primary: cs.CV (Computer Vision and Pattern Recognition)
  • Secondary: cs.CY (Computers and Society)
  • Alternative: cs.HC (Human-Computer Interaction)

🛠️ Advanced Compilation

Using latexmk (Automatic)

# Automatically handles multiple passes latexmk -pdf paper.tex # Clean auxiliary files latexmk -c

Manual Cleanup

# Remove auxiliary files rm -f *.aux *.log *.out *.toc *.bbl *.blg

📦 Required LaTeX Packages

All packages used are standard and included in most LaTeX distributions:

  • inputenc - UTF-8 encoding
  • fontenc - Font encoding
  • times - Times font
  • amsmath, amssymb - Math symbols
  • graphicx - Graphics support
  • hyperref - Hyperlinks
  • booktabs - Professional tables
  • algorithm, algorithmic - Algorithms
  • enumitem - List formatting
  • geometry - Page margins

🎨 Customization

Change Paper Size

% For US Letter \documentclass[11pt,letterpaper]{article} % For A4 (current) \documentclass[11pt,a4paper]{article}

Adjust Margins

% Current (1 inch) \usepackage[margin=1in]{geometry} % Wider margins \usepackage[margin=1.5in]{geometry}

Add Multiple Authors

\author{ Author One\thanks{Equal contribution}\\ NavGurukul Foundation\\ \texttt{author1@navgurukul.org} \and Author Two\thanks{Equal contribution}\\ NavGurukul Foundation\\ \texttt{author2@navgurukul.org} }

❓ Troubleshooting

Missing Packages Error

Problem: LaTeX complains about missing packages

Solution: Install the full TeX Live distribution:
sudo apt-get install texlive-full

Compilation Errors

  • Run pdflatex twice to resolve references
  • Check for special characters that need escaping: & % $ # _ { } ~ ^
  • Ensure all \begin{...} have matching \end{...}

Bibliography Issues

# If using BibTeX (not needed for this paper) pdflatex paper.tex bibtex paper pdflatex paper.tex pdflatex paper.tex

📄 Output Files

After successful compilation, you'll get:

  • paper.pdf - The final paper (keep this!)
  • paper.aux - Auxiliary file (can delete)
  • paper.log - Compilation log (can delete)
  • paper.out - Hyperref output (can delete)
