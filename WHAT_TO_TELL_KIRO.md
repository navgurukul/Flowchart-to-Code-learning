# 📱 What to Tell Me While Building the Android AR App

## 🎯 Quick Reference: Copy-Paste These Prompts

---

## ✅ Step 1: After Creating Project

**When:** You've created the project in Android Studio

**Tell me:**
```
I created the Android project with package org.navgurukul.org. 
What files should I create first?
```

**Or if you have errors:**
```
I created the project but getting this error:
[paste the error message]
```

---

## ✅ Step 2: After Adding Dependencies

**When:** You've added dependencies to build.gradle.kts and clicked Sync

**Tell me:**
```
Added dependencies and synced. What's next?
```

**Or if sync failed:**
```
Gradle sync failed with this error:
[paste the error from bottom panel]
```

---

## ✅ Step 3: After Creating Model Files

**When:** You've created ShapeType.kt and FlowchartShape.kt

**Tell me:**
```
Created model files. Ready for UI components.
```

**Or if you see red underlines:**
```
Getting "Unresolved reference" errors in [filename]:
[paste the error or screenshot]
```

---

## ✅ Step 4: After Creating UI Files

**When:** You've created ShapeCard, ShapeListScreen, ARViewScreen

**Tell me:**
```
Created all UI files. Ready to update MainActivity.
```

**Or if imports are red:**
```
Import errors in [filename]. What's wrong?
```

---

## ✅ Step 5: After Updating MainActivity

**When:** You've updated MainActivity.kt

**Tell me:**
```
Updated MainActivity. Ready to run the app!
```

**Or if you see errors:**
```
MainActivity has errors:
[paste the error]
```

---

## ✅ Step 6: After First Run

**When:** App runs successfully

**Tell me:**
```
App is running! I can see the shape list. What's next?
```

**Or if app crashes:**
```
App crashes on launch. Logcat shows:
[paste the error from Logcat - bottom panel]
```

## ✅ Step 7: Ready for AR Camera

**When:** Basic app works, ready to add AR

**Tell me:**
```
Shape list works perfectly. Ready to add AR camera functionality!
```

## 🐛 Common Issues - What to Tell Me

### Issue: Build Errors
```
Getting build error:
[paste the exact error message]
```

### Issue: Red Underlines in Code
```
Red underlines in [filename] at line [number]:
[paste the line of code or screenshot]
```

### Issue: App Won't Install
```
App won't install on my phone. Error:
[paste the error]
```

### Issue: Blank Screen
```
App opens but shows blank screen. No errors in Logcat.
```

### Issue: Camera Permission
```
App asks for camera permission but then crashes.
```

### Issue: ARCore Not Working
```
Getting "ARCore not supported" message on my phone.
What phone do I need?
```

## 📸 What to Share (If Needed)

### Screenshots Help!
1. **Error messages** - Screenshot of Android Studio errors
2. **Logcat** - Screenshot of crash logs (bottom panel)
3. **App screen** - What you see on your phone
4. **File structure** - Left panel showing your packages

### Code Snippets
If I ask "show me your code", copy-paste:
- The specific file I mention
- Or just the function/class with the error

---

## 🎯 Pro Tips

### ✅ DO Say:
- "Done with Step X, what's next?"
- "Getting this error: [error]"
- "App works! Ready for AR camera"
- "Which file should I edit?"

### ❌ DON'T Worry About:
- Long explanations - just tell me the status
- Perfect grammar - quick updates are fine
- Understanding everything - I'll guide you
